# Staten Island House Price Portal

Interactive Staten Island rolling sales dashboard with:

- charts;
- KPIs;
- ZIP code choropleth maps;
- filtering;
- CSV exports.

## Files

- index.html
- data.js

## Deployment

Upload both files to a GitHub repository root and enable GitHub Pages.
